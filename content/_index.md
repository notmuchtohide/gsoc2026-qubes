This website documents my work with [**Qubes OS**](https://www.qubes-os.org/) during Google Summer of Code 2026, on [**Graphical Package Manager Support in Templates**](https://doc.qubes-os.org/en/latest/developer/general/gsoc.html#graphical-package-manager-support-in-templates).



## Introduction

Qubes OS has made major improvements in its UX in recent years, and providing graphical interfaces for almost every task is a key part of that. It is becoming an easy and intuitive tool to achieve “reasonable” security, by relying on explicit compartmentalization and forces users to actively think about their actions, avoiding mistakes.

As cyber threats continue to evolve, Qubes OS is also becoming an essential tool for the general public, reinforcing the need for UX-focused software.



## Project Goals
The main goal of this project is to develop solutions capable of improving UX for software installation in templates, as a step to make Qubes OS more accessible for people from diverse backgrounds.
